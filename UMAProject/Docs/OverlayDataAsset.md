# OverlayDataAsset

`OverlayDataAsset` is a ScriptableObject that defines immutable data for an overlay: the textures, blend modes, and material that will be merged (atlased) onto a slot.

## Purpose
- Supplies the texture set (one per UMAMaterial channel) for a given overlay.
- Defines how the overlay blends over prior overlays (per-channel blend mode) and the draw rectangle inside the atlas.
- Optionally references an alpha mask, used instead of the alpha channel of the first texture.

## Key Fields
- `overlayName` (string): display and lookup name. `nameHash` is generated on serialize.
- `overlayType` (Normal/Cutout): selects merge shader for draw (opaque vs cutout path).
- `dontMergeDuplicates` (bool): if true, prevents merging overlays with identical inputs.
- `rect` (Rect): destination rectangle in the atlas (set by generator/combiner).
- `alphaMask` (Texture): optional alpha mask used during merging.
- `textureList` (Texture[]): textures in UMAMaterial channel order. In Addressables builds, textures may be stripped and restored by `textureNames`.
- `textureNames` (string[]): parallel to `textureList`, used to restore textures when stripped.
- `overlayBlend` (OverlayBlend[]): blend op per channel; base overlay is always Normal.
- `tags` (string[]): classification tags (used for filtering, hiding, wardrobe rules).
- `material` (UMAMaterial): describes shader mapping and properties for textures and colors.
- `materialName` (string): used by Addressables strip/restore to reload the UMAMaterial.
- `autoGeneratedLOD` (bool): flag for LOD-generated overlays.

## Methods/Helpers
- `GetBlend(int channel)`: safe read of a channel’s blend mode.
- `ValidateBlendList()`: resizes `overlayBlend` array to match `textureList` length.
- `GetTexture(string materialPropertyName)`: resolve texture by UMAMaterial property name.
- `GetAlphaMask()`: returns `alphaMask` or the first texture as mask source.

## Usage in UMA Pipeline
- Overlays are assigned to `SlotData` and processed by `TextureMerge` into atlas textures.
- Base overlay (first for a slot) uses material-specific base shader; additional overlays use blend shaders based on `overlayBlend`.
- When Addressables `StripTextures` is enabled, overlay textures are moved to their own addressable items; `textureNames` store the texture names for reload.

## Tips
- Ensure `textureList` order matches the UMAMaterial’s channels.
- For normal maps in arrays, follow the UDIM/array guidelines and shader encoding selection.
- Tags can be used to filter overlays programmatically (e.g., hide overlays by tag).

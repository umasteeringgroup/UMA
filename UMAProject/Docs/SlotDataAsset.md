# SlotDataAsset

`SlotDataAsset` is a ScriptableObject that contains the immutable slot definition: the mesh (`UMAMeshData`), default UMAMaterial, tags, and optional per-slot DNA and events. Runtime instances use `SlotData` to add overlays and per-instance adjustments.

## Purpose
- Provides the geometry and material definition for a slot (e.g., body, hair, clothing piece).
- Drives atlas generation and mesh combination via its UMAMaterial and channels.
- Optionally carries per-slot DNA converter and event hooks.

## Key Fields
- `slotName`/`nameHash`: identifier for indexing and lookup.
- `material` (UMAMaterial), `materialName`: material mapping and strip/restore support.
- `meshData` (UMAMeshData): vertices, normals, tangents, UVs, submeshes, bone data, blendshapes, cloth.
- `subMeshIndex`, `sourceSubmeshIndex`: submesh selection and source mapping.
- `overlayScale` (float): default overlay scale applied to overlays for this slot.
- `maxLOD` (int): highest LOD index this slot is shown on (-1 means never discarded).
- `useAtlasOverlay` (bool): whether overlays should be atlased in combiner for this slot.
- `animatedBones` (BaseUpdatedObject[]): bones to preserve/animate.
- `isClippingPlane`, `clippingPlaneOffset`: marks utility clipping plane slots.
- `isSmooshable`, `smooshOffset`, `smooshExpand`: smoosh system parameters.
- `slotDNA` (IDNAConverter via `DNAConverterField`): optional per-slot DNA adjustments.
- `SlotObject` (GameObject): optional object with `IUMAEventHookup` components for slot lifecycle events (`Begun`, `DNAApplied`, `Completed`, etc.).
- `slotGroup`, `tags`, `Races`: classification and filtering.
- `autoGeneratedLOD`: flag for LOD-generated slots.

## Important Methods
- `UpdateMeshData(SkinnedMeshRenderer, rootBoneName, udimAdjustment, submeshIndex, clearNormals, clearTangents)`: capture mesh into `UMAMeshData` from a SkinnedMeshRenderer.
- `EnsureBoneWeights()`: ensure managed bone weights are loaded into `UMAMeshData`.
- `BakeNewSlotData(BakeSlotParams)`: bake blendshapes into geometry and produce a new SlotDataAsset; optional smoothing and index registration.
- `Assign(SlotDataAsset source)`: copy metadata fields.

## Runtime Instance: SlotData
- `SlotData.asset`: reference to `SlotDataAsset` (immutable)
- Per-instance fields: `overlayScale`, `tags`, `Races`, `altMaterial`, `rendererAsset`, mesh hide mask, per-instance modifiers
- Overlay management: `AddOverlay`, `GetOverlayList`, `OverlayCount`, `RemoveOverlay`, `SetOverlay`, `GetEquivalentOverlay`
- Generation-time fields filled by the combiner: `skinnedMeshRenderer` index, `submeshIndex`, `vertexOffset`, `UVArea`, `UVSet`

## Pipeline
- UMA generator consumes SlotDataAssets + Overlays to build atlases with `TextureMerge`, then builds a combined SkinnedMeshRenderer with provided `UMAMeshData`.
- `SkinnedMeshCombiner` maps bones, submeshes, and build-time fields for runtime.

## Tips
- Keep `material` consistent with overlays intended for this slot; channel mismatches will warn.
- Use `maxLOD` to drop expensive slots at distance when using an LOD system.
- Use `BakeNewSlotData` to commit specific blendshapes to geometry and reduce runtime blendshape cost.

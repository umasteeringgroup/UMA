# Tileable material examples

The original four `*-PBR.png` catalogs and the eight new `* - PBR Catalog.png` sheets show all 108 materials rendered in Unity URP using Albedo, Normal, Roughness, Metallic and AO. `PBR Library Overview.png` shows the original 36; `Expansion PBR Overview.png` shows the new 72. The `* - Catalog.png` images show unlit albedo; `* - Repeat.png` shows a 2 × 2 repeat of the first tile in each set.

Use **+Fill > Add from Sprite Set...** in OverlayPainter and choose a set ending in **Tileable PBR**. New sets cover Rubber and Elastomers, Plastics and Coatings, Knits and Soft Clothing, Chainmail and Scale Armor, Technical Weaves and Composites, Brocade and Decorative Fabrics, Wood and Natural Materials, and Bone Horn and Keratin. The sprite assets are in the main plugin, under `Textures/Tileable Materials`; these examples are optional.

## Rebuild the sources

1. Install Python 3, numpy and Pillow in a suitable authoring environment. They are not required by the plugin.
2. From the Unity project root, run `python "Assets/UMA/OverlayPainterExamples/Tileable Materials/Authoring/generate_materials.py"` for the original four sets, and `python "Assets/UMA/OverlayPainterExamples/Tileable Materials/Authoring/generate_expansion.py"` for the eight new sets. Both retain the other catalog families. Resolution is 1024 per tile. Existing generated PNGs and previews are replaced; Sprite Set identities remain intact when reimported without changing names.
3. Copy `Authoring/ImportSpriteSets.cs.txt` to a temporary `.cs` outside Assets and run its `MaterialLibraryImport.Run` through a Unity editor script runner, or use the equivalent Sprite Editor slicing procedure. This importer uses Unity's supported Sprite data-provider APIs and preserves sprite IDs by name. It requires Unity's 2D Sprite and Newtonsoft JSON packages, present in the validation project. Its final validation report is written under `Build/Validation/TileableMaterials`.
4. Run `python "Assets/UMA/OverlayPainterExamples/Tileable Materials/Authoring/validate_materials.py"` for source maps and `python "Assets/UMA/OverlayPainterExamples/Tileable Materials/Authoring/validate_expansion_periodicity.py"` for periodic fields. Run `TileableMaterials` in the separate Tests companion for Unity import validation. Those tests target the shipped 1K/3 × 3 layout.

The optional Height sheet is a 16-bit PNG source. It is excluded from the Sprite Set to avoid applying the same surface relief twice. To use it, replace the Normal channel with Normal Control and select the corresponding Height sprite. See the main plugin's **Tileable Material Sprite Sets** guide for import conventions and category references.

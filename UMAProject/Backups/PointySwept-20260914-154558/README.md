# PointySwept before restoration

This folder preserves the complete PointySwept example as it was immediately
before the user-requested restoration on 2026-09-14. All files and metadata were
copied and verified byte-for-byte. It is outside Assets to avoid duplicate GUIDs.

The live example's groom, ribbon profile, hair material and scalp-color modifier
were restored to the originally supplied version. Existing repaired import metadata,
code fixes, unrelated assets and recovery snapshots were retained.

To recover these edits later, close Unity and copy only the desired asset files
back to their matching paths under
`Assets/UMAProjectData/HairCards/Examples/PointySwept`.
Do not import this entire backup as a second copy alongside the live example.
